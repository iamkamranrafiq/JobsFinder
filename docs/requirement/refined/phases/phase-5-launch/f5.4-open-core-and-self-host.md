## Summary
Publish the core platform as open source with a polished README and a one-command self-host (Docker Compose). Managed hosting and managed inference remain the paid offering.

## Scope
**In:**
- Public repo hygiene: README, contributing guide, issue templates
- `docker compose up` self-host with BYOK
- Self-host configuration docs (Apify token, AI key, email)

**Out:**
- Choosing the licence (pending)

## Business rules
1. A self-hosted instance runs in single-user mode with BYOK and the operator's own Apify token. No managed services are required.
2. Self-hosted instances default to DryRun, like the hosted product.
3. No secrets or production configuration are in the public repo.

## Acceptance criteria
1. **Phase 5 exit (part):** given a fresh machine with Docker, then following the README starts a working instance in ≤ 15 min.
2. Given the public repo, then secret scanning finds nothing.

## Decisions (2026-11-22)
- **D12 - Single-user mode:** this needs a definition before estimating. Proposed: auto-provision one tenant with unlimited entitlements. Self-host also needs a Linux-capable vault implementation, because `DpapiLocalVault` (F1.6) is Windows-only.
- **D13 - Licence:** the Stories are created now. Only the LICENSE file, licence statements and the switch to a public repo wait for the licence decision (F5.6).
