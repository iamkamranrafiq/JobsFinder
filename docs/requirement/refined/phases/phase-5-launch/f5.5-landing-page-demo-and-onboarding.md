## Summary
A public landing page with a live DryRun demo for anonymous visitors, a docs site, and a guided onboarding flow aimed at the first approved application within 24 h.

## Scope
**In:**
- Landing page
- Anonymous DryRun demo (sample CV and jobs; no personal data stored)
- Docs site
- Onboarding wizard:
  1. upload CV
  2. confirm the profile, including current employer
  3. set targets
  4. choose autonomy
  5. optionally answer diversity questions
  6. add a BYOK key (Free plan)
- Activation tracking

## Business rules
1. Anonymous visitors can only use the demo. Every real feature requires sign-in.
2. The demo uses sample data and never runs a real channel.
3. Onboarding sets autonomy to DryRun unless the user chooses otherwise.

## Acceptance criteria
1. Given an anonymous visitor, then the demo shows a full DryRun cycle on sample data, and no data is stored.
2. Given a new user completing onboarding, then they land on a populated dashboard after their first cycle.
3. The activation metric (first approved application within 24 h) is measured.

## Decisions (2026-11-22)
- **D7 - Wizard order:** for Free users, the BYOK step comes first, because CV parsing needs a model.
- **D11 - Docs site:** JF-151 has no acceptance criteria yet and needs them before it is built.
- **D14 - "Approved":** in the activation metric, "approved" means approved in the review queue (F3.4). F6.4 referral credit uses the same definition.
- **D15 - Demo abuse:** the anonymous demo is rate-limited and uses fake providers only, so it makes no real AI calls.
