## Summary
A minimal API and a single Angular page that run one end-to-end DryRun cycle: fetch jobs -> pick one Greenhouse job -> fill its form (no submit) -> show the result with the screenshot.

## User stories
- As the owner, I run one end-to-end DryRun from my real CV to prove the loop works.

## Scope
**In:**
- `POST /cycles/run` (DryRun only) and `GET /cycles/{id}`
- A background worker running the stages in order
- An Angular page: upload CV, fetch jobs, pick a job, run, view the outcome and screenshot

**Out:**
- Fit scoring (F2.6)
- Auth (F1.1)
- SignalR (F4.3); the page polls instead

## Business rules
1. The cycle runs in a background worker, never on the request thread. The API returns `202 Accepted` with the cycle id.
2. The outcome is one of `Prepared`, `NeedsYou(reason)` or `Failed(reason)`. `Submitted` cannot occur in Phase 0.

## Acceptance criteria
1. Given an uploaded CV and sourced jobs, when I run a cycle on a Greenhouse job, then within 3 min the page shows `Prepared` and the filled-form screenshot.
2. Given a hand-off, then the page shows `Needs you` with the reason.
3. **Phase 0 exit:** one end-to-end DryRun from a real CV succeeds and is demonstrated.

## Edge cases
- The API restarts during a cycle -> the cycle is marked `Failed(Interrupted)`. Resuming arrives with the durable queue in F1.3.

## NFRs
