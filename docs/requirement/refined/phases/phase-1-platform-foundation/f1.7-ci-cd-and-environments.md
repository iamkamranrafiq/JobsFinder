## Summary
A GitHub Actions pipeline and Local -> Staging -> Production environments, with every non-production environment forced into DryRun.

## Scope
**In:**
- PR workflow: build, unit and integration tests (Testcontainers), lint (`dotnet format`, ESLint), Playwright e2e, Dependabot, secret scanning
- Main workflow: build and push images (API, worker, browser worker), run migrations, deploy to staging, smoke-test, manual promotion to production
- Docker Compose for local development

## Business rules
1. A PR cannot merge unless every check is green.
2. Every non-production environment is **forced to DryRun** by configuration that cannot be overridden by users.
3. Secrets are injected at runtime from the secret store. None are baked into images or committed. Each environment has its own credentials.
4. Migrations are forward-only and reviewed in the PR.

## Acceptance criteria
1. **Phase 1 exit:** CI is green on main, with the two-tenant isolation tests (F1.2) included.
2. Given a staging deployment, when any apply runs, then it can never reach `Submitted` (an automated smoke test asserts this).
3. Given a committed secret, then the secret-scanning check fails the PR.
