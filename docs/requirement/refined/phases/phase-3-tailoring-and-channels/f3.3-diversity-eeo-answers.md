## Summary
Users may answer common diversity questions once: gender, ethnicity, disability, veteran status, pronouns. The answers are stored encrypted and used only to fill matching form fields. This is sensitive data, under explicit consent.

## User stories
- As a user, I answer diversity questions once instead of on every form.
- As a user, I can choose "Prefer not to say", change my answers, or delete them at any time.

## Scope
**In:**
- `GET/PUT/DELETE /profile/eeo`
- A separate consent step
- Encrypted `EeoAnswers`
- Mapping answers to form options during apply
- An optional step in onboarding

## Business rules
1. Collected only after explicit, separate consent, with a timestamp. Without consent, nothing is stored.
2. Every question offers **"Prefer not to say"**.
3. Encrypted with the per-tenant data key. **Never sent to the AI model.** Form fields are matched to answers deterministically, with no model involved.
4. Deleting the answers removes them permanently and is recorded in the audit log (without the values).
5. A diversity question with no stored answer -> Needs you (E15). The user can answer it and optionally save the answer.

## Acceptance criteria
1. Given no consent, then the diversity form cannot be saved.
2. Given stored answers, then the database holds only ciphertext.
3. A test asserts that no `IAIProvider` request payload ever contains diversity values.
4. Given I delete my answers, then subsequent diversity questions go to Needs you.
