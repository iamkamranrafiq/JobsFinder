## Summary
Whenever the agent cannot proceed honestly, it stops and hands the application back to the user with context and a direct link. It never attempts a bypass.

## Scope
**In:**
- `HandedToHuman(reason)` with these reasons:
  - `Captcha`
  - `Mfa`
  - `LoginWall`
  - `Payment`
  - `NativeApply`
  - `UnknownField`
  - `Unconfirmed`
  - `Salary`
  - `MailboxDisconnected`
  - `ModelError`
- A "Needs you" view
- A deep link to the original posting
- Partial artifacts (tailored CV, cover letter) available to download for applying manually

## Business rules
1. Hard stops apply at **every** autonomy level.
2. There is no CAPTCHA solving, MFA defeat or bot-evasion code anywhere in the codebase.
3. LinkedIn Easy Apply and Indeed Apply postings always hand off as `NativeApply` (E2).
4. A hand-off never counts against the daily limit and is never shown as Submitted.
5. The user can dismiss a hand-off (for example after applying on the site themselves). It is recorded as `Skipped` and leaves the tracker. The platform never records it as `Submitted`, because it did not submit.

## Acceptance criteria
1. Given each hard-stop reason, then an automated test proves the run ends in `NeedsYou(reason)` and no bypass is attempted.
2. Given a `NativeApply` posting, then the user sees the tailored CV and cover letter to download and a link to the posting.
3. Given I dismiss a hand-off, then it leaves the tracker as `Skipped`, uses no daily limit, and is never counted as `Submitted`.
