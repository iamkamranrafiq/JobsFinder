## Summary
For each role above the threshold, generate a tailored CV (the same facts with better emphasis) and a cover letter or outreach email in the user's voice. A diff shows exactly what changed.

## User stories
- As a user, I get a CV that foregrounds what this role values, without anything invented.
- As a user, I see a diff of the tailored CV against my original before approving.

## Scope
**In:**
- `IContentGenerator` (Opus-class)
- `TailoredCv` schema
- Cover-letter / email generation
- Conditioning on the user's voice (optional writing samples)
- Diff view data
- Rendering the tailored CV to PDF
- `GeneratedArtifact` storage and caching

## Business rules
1. **The agent never adds** skills, experience, employers, dates or achievements that are not in the profile. It may only reorder, select and rephrase.
2. A post-generation check compares the tailored CV with the profile. Any skill, employer or date not found in the profile fails the check, and the content is regenerated (at most 2 times), then the item becomes Needs you.
3. If the user's own edit adds a skill that isn't in the profile, it is allowed with a visible warning and recorded in the audit log (D11 / E18).
4. Artifacts are cached per (profile version, posting).

## Acceptance criteria
1. Given a role and a profile, then a tailored CV PDF, a cover letter and a diff are produced.
2. Given generated content containing a skill not in the profile, then the honesty check rejects it, and after 2 failed retries the item is `NeedsYou(ModelError)`.
3. Given I add "Kubernetes" (not in my profile) during edit-then-approve, then a warning is shown and the edit is audit-logged.
4. A test asserts that the generator's system prompt forbids inventing facts, and that a fixture with an injected fake skill is rejected.

## NFRs
- Tailoring one role takes < 60 s p95.
