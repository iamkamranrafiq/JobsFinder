## Summary
Fill and submit public ATS application forms with Playwright. There are tuned adapters for Greenhouse, Lever, Workable and Ashby, and a generic field mapper for other forms. The channel pauses before submit, and only marks `Submitted` when the site shows its confirmation.

## Scope
**In:**
- `WebFormChannel` and `AtsChannel` adapters (4 ATS)
- The generic mapper
- Filled-form screenshot
- Submit on approval
- Confirmation detection
- Browser session pool (≤ 3 per worker)

**Out:**
- Logging in to anything
- LinkedIn / Indeed native apply (hand-off, F3.7)

## Business rules
1. The channel fills every field it can, then **stops before the final submit** and produces a screenshot for review. Submitting happens only after approval or an allowed auto-submit (F4.2).
2. **Submitted** only when the site displays its confirmation page or message. Confirmation detection is defined per adapter; the generic mapper uses confirmation text and URL patterns.
3. If submit was clicked but no confirmation was detected (timeout, error page or ambiguous page), the result is `HandedToHuman(Unconfirmed)`. It is never retried automatically (E10).
4. The pages loaded are public apply pages only. No credentials are used.

## Acceptance criteria
1. **Phase 3 exit:** review-first applications succeed end-to-end on at least 3 of the 4 ATS in staging-like test pages, and in production on real postings.
2. Given an approved item and a confirmation page after submit, then the status is `Submitted`, with the confirmation evidence (screenshot or text) stored.
3. Given a timeout after submit, then the status is `NeedsYou(Unconfirmed)` and no second submit happens.
4. Given an unknown ATS form, then the generic mapper fills what it can, and any unanswerable required field leads to `NeedsYou(UnknownField)`.

## NFRs
- One apply (fill + screenshot) takes < 2 min p95.
- Submission reliability ≥ 95%.
